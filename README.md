# "আমার যুগিখালী" (Amr Jugikhali - Smart Union Portal)
### মাওলানা আব্দুল লতিফ - চেয়ারম্যান পদপ্রার্থী, ১২ নং যুগিখালী ইউনিয়ন পরিষদ

বাংলাদেশ জামায়াতে ইসলামী মনোনীত চেয়ারম্যান পদপ্রার্থী **মাওলানা আব্দুল লতিফ** সাহেবের নির্বাচনী প্রচারণা ও ডিজিটাল জবাবদিহিতা পোর্টাল।

---

## 🌟 প্রধান প্রধান ফিচারসমূহ

1. **হিরো ব্যানার ও পরিচিতি:** মাওলানা আব্দুল লতিফ সাহেবের উচ্চমানের ছবি, দলীয় মনোনয়ন, নির্বাচনী বার্তা ও স্লোগান।
2. **ইন্টারেক্টিভ সমর্থন (Pledge Support):** কনফেটি সেলিব্রেশন অ্যানিমেশনসহ ভোটারদের সরাসরি সমর্থন জানানোর ব্যবস্থা।
3. **৪টি মূল স্তম্ভের নির্বাচনী ইশতেহার:** সুশাসন, নাগরিক সেবা, স্বাস্থ্য/শিক্ষা, এবং জবাবদিহিতা।
4. **স্মার্ট প্রমিজ ট্র্যাকার (Smart Promise Tracker):** রিয়েল-টাইম কাজের শতকরা (%) অগ্রগতি বার, ক্যাটাগরি ও ফিল্টারসহ।
5. **নাগরিক অভিযোগ ও সমস্যা বক্স (Grievance Box):** ঘরে বসে রাস্তাঘাট, পানি বা দুর্নীতির অভিযোগ দাখিল এবং ট্র্যাকিং কোড দিয়ে অগ্রগতির খোঁজ নেওয়ার ব্যবস্থা।
6. **জরুরি সেবা ও ব্লাড ডোনার ডিরেক্টরি:** ১-ক্লিকে অ্যাম্বুলেন্স, পুলিশ, ফায়ার সার্ভিসের কল এবং রক্তের গ্রুপ অনুযায়ী ডোনারের তালিকা।
7. **বাজেট ও অর্থ স্বচ্ছতা:** সরকারি অনুদান ও উন্নয়ন ব্যয়ের হিসাব উন্মুক্ত প্রকাশ।
8. **কৃষি ও কৃষক কর্নার:** অনুমোদিত সার-বীজ ডিলার তালিকা, সরকারি নির্ধারিত দামের তালিকা এবং কৃষি কর্মকর্তা হেল্পলাইন।
9. **ঘুষমুক্ত নাগরিক সেবা গাইড:** জন্মনিবন্ধন, উত্তরাধিকার ও ভাতার অনলাইন গাইড।
10. **সম্পূর্ণ সুরক্ষিত অ্যাডমিন ড্যাশবোর্ড (`/admin`):**
    - পিন/পাসওয়ার্ড দিয়ে নিরাপদ লগইন (ডিফল্ট পিন: `1234`)।
    - যেকোনো প্রতিশ্রুতির অগ্রগতি (%) পরিবর্তন।
    - নাগরিকদের অভিযোগ দেখা, স্ট্যাটাস পরিবর্তন ও সমাধানের উত্তর প্রদান।
    - প্রার্থীর স্লোগান ও বক্তব্য এডিটর।
    - বাজেট হিসাব পরিবর্তন।

## 🚀 Vercel-এ ফ্রিতে হোস্ট করার নিয়ম

এই প্রজেক্টটি **Next.js 15 (App Router)** দিয়ে তৈরি, যা Vercel-এ **১০০% বিনামূল্যে** চলে।

### ধাপ ১: গিটহাবে কোড পুশ করুন
```bash
git init
git add .
git commit -m "Complete Amr Jugikhali Campaign Website"
git branch -M main
git remote add origin https://github.com/আপনার-ইউজারনেম/lotif-chairman.git
git push -u origin main
```

### ধাপ ২: Vercel-এ ডিপ্লয়
1. [Vercel.com](https://vercel.com)-এ গিয়ে GitHub দিয়ে লগইন করুন।
2. **"Add New Project"** এ ক্লিক করে আপনার রিপোজিটরিটি সিলেক্ট করুন।
3. **"Deploy"** বাটনে চাপ দিন। ২ মিনিটের মধ্যে আপনার ওয়েবসাইট লাইভ হয়ে যাবে!
